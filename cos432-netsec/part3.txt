How we obtained this:
The firewall's internal IP (10.0.108.169) was found via `ip addr` after SSH-ing into the firewall, and its public IP (18.189.157.251) was provided as the SSH endpoint when we finish question 2. 
The mainframe's IP (10.0.53.171) was discovered by examining the nginx configuration file (`/etc/nginx/nginx.conf`) on the firewall, which contained a `proxy_pass` directive forwarding traffic to `http://10.0.53.171:47923/admin`.

The employee's internal IP (10.0.19.17) was identified from the system prompt (`bob@ip-10-0-19-17`) after successfully SSH-ing into the employee machine.
