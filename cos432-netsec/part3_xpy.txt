I decrypted the WiFi traffic in part3.pcap using the cracked WPA2 password and the SSID (COS432_MegaCorp) in Wireshark's 802.11 decryption settings. The decrypted ARP frames revealed the employee's IPs (10.8.185.117 and 192.168.0.101) and the WiFi gateway (192.168.0.1). The mainframe's IP (10.0.53.171) was discovered by examining the nginx configuration file (`/etc/nginx/nginx.conf`) on the firewall, which contained a `proxy_pass` directive forwarding traffic to `http://10.0.53.171:47923/admin`.

First, I examined the nginx configuration file (/etc/nginx/nginx.conf) on the firewall and discovered a proxy_pass directive forwarding requests from /proxy_test to http://10.0.53.171:47923/admin. Since this proxy uses unencrypted HTTP, I used tcpdump -i eth0 -A host 10.0.53.171 on the firewall to capture traffic between the firewall and the mainframe. In the captured packets, I found an HTTP Basic Authentication header (Authorization: Basic YWRtaW46RmExWlF4c0FERVVMbFcwbnppdG5vcFgwMQ==). I decoded this Base64 string to obtain the credentials admin:Fa1ZQxsADEULlW0nzitnopX01. Using these credentials, I accessed the admin page on the mainframe (curl -u admin:Fa1ZQxsADEULlW0nzitnopX01 http://10.0.53.171:47923/admin/), which revealed FTP login credentials — username: bob, password: super-unbruteforceable-sketchycorp-employee-password. I then used nmap -Pn -sV 10.0.53.171 -p 200-300 to discover an FTP service (vsftpd) running on port 234 of the mainframe. I connected via ftp 10.0.53.171 234, logged in with Bob's credentials, navigated to the bob directory, and downloaded the client list file.
